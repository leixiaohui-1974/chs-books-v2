## 1. CPSS统一框架

CPSS（Cyber-Physical-Social Systems，信息-物理-社会系统）是CHS全系列书稿的统一屋顶。

### 1.1 三空间定义

- **Physical空间**：水物理过程——河道、水库、管网、水文循环、闸门、泵站
- **Cyber空间**：数字孪生、模型、算法、控制器、AI——一切信息处理
- **Social空间**：调度规程、法规、利益博弈、人类决策、社会需求

### 1.2 CHS六元组到CPSS的映射

| CHS元素 | CPSS空间 | 说明 |
|---------|---------|------|
| P (Physical) | Physical | 水物理过程 |
| A (Actuation) | C→P界面 | 执行器（闸门、泵站） |
| S (Sensing) | P→C界面 | 传感器、遥测 |
| D (Digital Twin) | Cyber | 水文/水力模型、数字孪生 |
| C (Control) | Cyber | 决策引擎（PID/MPC/RL/LLM） |
| O (Operation) | Social | 目标约束（防洪标准、供水保证率） |

关键洞察：O属于Social空间，目标不是技术决定的，而是社会协商的。

### 1.3 三重反馈回路

水系统有三重嵌套反馈，不仅仅是Physical↔Cyber：

```
回路1 (秒~分钟级)：Physical ↔ Cyber
   水位偏差 → PID/MPC计算 → 闸门动作 → 水位变化

回路2 (小时~天级)：Cyber ↔ Social
   预报来了洪水 → 调度方案优化 → 调度员审批/修改 → 下发执行

回路3 (月~年级)：Social ↔ Physical
   下游城市扩张 → 防洪标准提高 → 水库调度规程修编 → 工程改造
```

水系统复杂性的真正来源不是物理过程复杂，而是三个空间的耦合反馈复杂。

## 2. 智能体统一定义

Agent = (Perception, Decision, Action, Objective, Environment)

PID/MPC/RL/LLM Agent都是同一范式的不同实现，差异仅在决策机制复杂度。反馈原理不变。

| 维度 | PID | MPC | RL | LLM Agent |
|------|-----|-----|-----|-----------|
| 感知 | 偏差e(t) | 状态向量 | 状态观测 | 文本/工具返回值 |
| 决策 | Kp+Ki+Kd | 滚动优化 | 策略网络π(s) | LLM推理+规划 |
| 行动 | 阀门开度 | 控制序列首元 | 离散/连续动作 | 调用工具 |
| 目标 | e→0 | min代价函数 | max累计奖励 | 完成指令 |
| 反馈 | 测量偏差 | 模型预测+实测修正 | 环境奖励 | 执行结果 |

## 3. 闭环 vs 开环

### 3.1 时间步内闭环（控制）

每个时间步内，多模型耦合迭代，达到一致后推进下一步：
- 预报模型 ↔ 水力模型 ↔ 优化模型 在每个时间步内交互
- 每步都有可执行决策

### 3.2 开环串行（仿真）

模型A跑完全部时间步 → 传结果给模型B → B跑完全部时间步：
- 模型间没有反馈，误差单向累积
- 全部算完才有结果

**当前水利行业四预的主流做法是开环串行，应该是时间步内闭环。**

## 4. 确定性/灵活性工作流谱系

| 空间 | 工作流特性 | 原因 |
|------|-----------|------|
| Physical | 严格确定性 | 物理因果律不可违背 |
| Cyber | 混合 | 算法流程确定，策略可自适应 |
| Social | 高度灵活 | 人类决策情境依赖 |

### 与AI工作流概念的映射

| AI概念 | 工程概念 | 本质 |
|--------|---------|------|
| Sequential Chain | 开环串行 | 无反馈 |
| Agent Loop (ReAct) | 时间步内闭环 | 感知-决策-执行-反馈 |
| Human-in-the-Loop | OIL | Social↔Cyber界面 |
| DAG Workflow | 确定性工作流 | 步骤预先固定 |
| Dynamic Routing | 灵活工作流 | 运行时根据状态选择 |
| Retry/Fallback | 降级/四态机 | 异常处理 |

## 5. 四预闭环重构

四预（预报、预警、预演、预案）不是四个串行环节，而是CPSS三空间在每个时间步内的闭环耦合：

- **预报** = Sensing + Digital Twin 的前向推演
- **预警** = ODD状态评估（实时判断是否接近边界）
- **预演** = XIL验证（MIL/SIL/HIL/OIL对应预演四层）
- **预案** = Control的实时决策输出（不是静态文档，是活的动态决策）

### 宏观 vs 实时尺度

| | 宏观（天~周） | 实时（分钟~小时） |
|--|-------------|-----------------|
| 控制类型 | 开环优化+滚动修正 | 严格闭环，时间步内耦合 |
| 四预形态 | 方案比选 | 每步闭环输出 |
| 工作流 | 灵活(Social主导) | 确定性(Physical主导) |

## 6. WNAL的CPSS本质

WNAL = Social空间向Cyber空间的决策权渐进让渡：
- L0-L1: Social完全控制
- L2: Cyber决策, Social监督
- L3: Cyber自主(ODD内), Social设定边界 ← 质变点
- L4-L5: Cyber主导
