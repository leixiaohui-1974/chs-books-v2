# Plan — Phase 1: T1理论卷CPSS重构

## Goal

在T1理论卷中建立全系列的理论根基：CPSS统一框架、智能体统一定义、闭环/开环区分、四预闭环、工作流谱系。

## Current State Analysis

- **ch02** (控制论视角): 已有优秀的Wiener/钱学森溯源和CHS定位，缺智能体统一定义
- **ch03** (八原理概览): 已有八原理总论，缺CHS六元组→CPSS三空间映射
- **ch07** (八原理详述): 已有详细八原理展开，缺"反馈作为元原理"论述
- **ch08** (CPSS框架): **最大问题** — 当前内容聚焦水电站CPSS（水力-机械-电气耦合），非常窄。需要大幅重构为CPSS作为水系统控制论的统一框架
- **ch10** (WNAL): 已有完整WNAL体系，缺CPSS视角解读
- **ch14** (物理AI与认知AI): 已有HydroCore/HydroClaw双引擎，需增加agent统一视角
- **ch15** (验证与展望): 已有点-链-网验证，缺CHS学术定位声明

**Task 1.1: ch02 增加智能体统一定义** [T1-01]

**Task 1.2: ch03 增加CHS六元组→CPSS映射** [T1-02]
- 位置: §3.1之后，新增一节"§3.x CHS六元组的CPSS映射"
- 内容:
  - CHS六元组 Σ=(P,A,S,D,C,O) 到CPSS三空间的映射表
  - P/A→Physical空间, S/D/C→Cyber空间, O→Social空间

  - 与八原理的关联: 八原理覆盖了三个空间的不同层面
- 风格: 简洁概览，呼应八原理结构

**Task 1.3: ch07 增加"反馈作为元原理"** [T1-03]
- 位置: §7.1.2（五层结构与依赖关系）之后，新增段落或小节
- 内容:
  - 论述: 八原理都是反馈原理在不同维度的展开
  - P1传递函数化=建立反馈通道的数学模型
  - P2可控可观性=确保反馈通道的完整性
  - P3分层分布式=多层反馈回路的组织
  - P4安全包络=反馈的硬约束边界
  - P5在环验证=反馈通道的正确性验证
  - P6认知增强=反馈信息的语义理解
  - P7人机共融=Social↔Cyber的反馈界面
  - P8自主演进=反馈驱动的系统学习
  - 一句话: "反馈是CHS的元原理(meta-principle)，八原理是其在不同维度的工程展开"
- 风格: 紧凑论述，不超过500字

**Task 1.4: ch10 增加WNAL的CPSS解读** [T1-06]
- 位置: §10.1.2（WNAL设计目标）之后或§10.2末尾，新增段落
- 内容:
  - WNAL的CPSS本质: Social空间向Cyber空间的决策权渐进让渡
  - L0-L1: Social完全控制, Cyber仅辅助
  - L2: Cyber决策, Social监督
  - L3: Cyber自主(ODD内), Social设定边界
  - L4-L5: Cyber主导, Social仅做战略决策
  - 与多域能力矩阵的结合: 各域独立评级，系统取最低(木桶效应)
- 风格: 延续ch10的SAE类比风格

**Task 1.5: ch15 增加CHS学术定位声明** [T1-08]
- 位置: 全书结语部分，新增段落
- 内容:
  - CHS是CPSS范式在水利领域的具体实例化
  - 以反馈为核心公理，通过六元组描述水系统CPSS耦合结构
  - ODD定义运行边界，SE保证安全约束，WNAL度量人机协同自主程度
  - 一切智能体(PID/MPC/RL/LLM)都是Cyber空间中决策组件的不同实现
  - 这一统一视角的学术意义: 不是AI涵盖了控制，而是控制论涵盖了AI Agent
- 风格: 学术总结性质，庄重

### Wave 2: ch08重构 + ch14重构（依赖Wave 1的概念）

**Task 2.1: ch08 大幅重构** [T1-04, T1-05]
- 这是Phase 1最大的任务
- 当前ch08聚焦水电站CPSS（水力-机械-电气耦合），需要在保留现有内容的基础上，大幅扩展CPSS作为统一框架的论述
- 修改策略:
  - §8.1引言扩展: 从水电站场景提升到水系统控制论的统一框架层面
  - 新增§8.x: CPSS三空间与三重反馈回路
    - Physical↔Cyber(秒级): 传感器→控制器→执行器
    - Cyber↔Social(小时级): 优化方案→调度员审批→执行
    - Social↔Physical(年级): 社会需求变化→工程改造
    - 水系统复杂性来源 = 三空间耦合，不仅是物理过程
  - 新增§8.x: 确定性/灵活性工作流谱系
    - Physical空间→确定性(物理因果律)
    - Social空间→灵活性(人类决策情境依赖)
    - Cyber空间→混合
    - 与AI workflow概念的桥接(DAG=确定性, Dynamic Routing=灵活)
  - 新增§8.x: 闭环vs开环范式
    - 时间步内闭环(多模型耦合迭代) = 控制
    - 模型串行(A跑完再跑B) = 仿真
    - 对照图: 两种范式的架构图
  - 新增§8.x: 基于CHS的四预闭环体系
    - 四预不是四个串行环节
    - 预报=S+D前向推演, 预警=ODD状态评估, 预演=XIL验证, 预案=C实时决策输出
    - 宏观尺度(灵活工作流,Social主导) vs 实时尺度(确定性工作流,Physical主导)
    - 多模态运行(G0-G4)作为工作流切换的论述素材
  - 保留现有水电站CPSS内容作为一个具体应用示例
- 风格: 这是理论卷的核心章节，需要学术严谨+工程直觉并重
