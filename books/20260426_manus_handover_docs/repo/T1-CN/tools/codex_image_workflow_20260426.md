# T1-CN 本机 Codex CLI 生图工作流（2026-04-26）

本工作流用于在**不执行任何登录动作**的前提下，直接复用用户本机 `.codex` 中既有认证与配置环境，为第一卷生成新的中文教材插图文件。当前路线已经验证可行，首张成功样例为 `T1-CN/H/fig_01_02_codex_20260426.png`。

## 工作原则

| 项目 | 约束 |
|---|---|
| 认证方式 | 只使用本机 `.codex` 现有配置，不重新登录，不改写认证文件 |
| 文件策略 | 一律输出为**新文件名**，不得覆盖用户手工生成的现有图片 |
| 图件风格 | 学术教材风格、白色背景、蓝色主调、中文标注、扁平矢量感、横向 4:3 |
| 内容表达 | 以结构图、流程图、层级图、对比图为主，避免海报化与宣传图风格 |
| 生成优先级 | 第一章与第三章优先，先完成课程核心图件 |

## 推荐调用方式

在仓库根目录下执行：

```bash
export PAGER=cat GIT_PAGER=cat TERM=dumb NO_COLOR=1 CLICOLOR=0
codex exec --color never --dangerously-bypass-approvals-and-sandbox \
  --skip-git-repo-check \
  -C /Users/rainfields/hydrosis-local/research/chs-books-v2 \
  -o /tmp/codex_task_last.txt \
  - < T1-CN/tools/<prompt_file>.txt
```

之所以加入这些环境变量，是为了尽量避免分页器干扰、终端彩色输出截断与不必要的交互停顿，从而让命令更稳定地返回结果。

## 提示词写法基线

提示词应采用完整中文任务说明，明确写出“这是新文件，不得覆盖现有图件”，并且把图题、布局、节点、箭头方向、标签语言、字体可读性和教材用途说明清楚。对于流程和框架类插图，还应显式要求不要写实、不要 UI 截图风、不要中英双语大段混排，以降低风格漂移风险。
