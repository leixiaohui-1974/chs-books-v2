# T5 第6章图表任务与来源追踪文件

## 一、使用说明

本文件服务于 T5 第6章《从方法有效到运行可信：xIL、ODD 与安全包络的部署闸门》的正式写作、图表执行与后续审校。其核心目标，是把本章的部署语言压缩成可以检查、可以放行、可以回退的正式闸门结构。本章图表必须承担三项任务：第一，说明 xIL、ODD 与安全包络为何必须联合作为放行条件；第二，说明 ODD 和安全包络不是抽象术语，而是具体边界集合；第三，说明从离线通过到现场放行之间存在多层门槛与人工覆盖接口。

## 三、每个任务项的详细执行约束

### 3.1 Fig-1 部署闸门总图

该图是本章最重要的图件。它必须清楚表达：xIL 负责验证系统在接口和环境中的表现，ODD 负责界定系统被允许工作的运行域，安全包络负责规定在该运行域中仍不可越过的动作与状态边界。三者缺一不可，且都必须保留人工覆盖和回退接口。

### 3.2 Tab-1 闸门对照表

该表的任务，是把部署闸门从抽象概念压缩成审查清单。它应让读者看到：某个部署方案若不能明确说明自己的 ODD 条件、包络约束、验证证据和放行条件，就不能被视为运行可信系统。

### 3.3 Fig-2 分层闸门流程图

该图用于强调多层放行。建议按时间顺序呈现：离线通过并不代表可现场放行；仍需在环验证确认接口与环境一致，再确认是否处在既定 ODD 内，再确认安全包络与人工覆盖条件是否到位，最后才进入运行监测阶段。这样才能避免“测试更多”等同于“部署更安全”的误解。

### 3.4 Box-1 超出 ODD 案例框

案例框应说明：一个算法即便在自己的设计域内表现优秀，只要被部署到超出 ODD 的场景，风险就会被放大。重点不在算法失败本身，而在“域边界未被明示和执行”这一治理缺陷。
