## 一、第一批三卷出版社匹配表

| 卷 | 推荐出版社（优先级） | 类型 | 配套要求 |
|----|------|------|---------|
| **T2-CN《水网觉醒》** | 1. 中信出版社 / 2. 湛庐文化 / 3. 人民邮电出版社（图灵或异步社区） | 平装科普 | 配封面美术；支持衍生阅读音频版 |
| **T2a《建模与控制》** | 1. 高等教育出版社（研究生教材） / 2. 清华大学出版社（备选） | 精装研究生教材 | **强制要求**：习题解答手册、PPT 课件、代码仓库、数字孪生案例数据 |
| **T2b《认知AI工程版》** | 同 T2a（同时投递）；1. 高等教育出版社 / 2. 清华大学出版社 | 精装研究生教材 | 同 T2a；可与 T2a 打包推介为"CHS 教材双子卷" |

**规避项**：
- T2-CN 不要送水利行业出版社（限制读者面）
- 三卷不要分别送不同综合出版社（书系一致性会被破坏）
- 不要选纯电子书优先的渠道（学术教材的纸质出版仍是国家重点教材认证的硬性条件）

## 四、阻塞项清单（投稿前必解决）

按严重程度排列：

### 🔴 阻塞投稿

1. **T2a / T2b 缺习题解答手册**——研究生教材送审硬性要求。需要专门组织习题答案撰写，估算工作量 1—2 周（如果由研究生团队配合）。
2. **T2a / T2b 缺配套代码仓库**——研究生教材的"数字资源"组成部分。需要建立 GitHub 仓库并发布最小可运行示例。

### 🟡 强烈建议解决

3. **T2-CN 的章节插图**——目前书稿中只有提示词。委托美术设计需要 2—4 周时间。出版社可以在投稿后委托，但建议先准备 5—10 幅样图作为投稿附件。
4. **作者简介 + 内容提要 + 推荐序**——投稿稿件标准附件，需提前准备。

### 🟢 可在审稿期间补

5. **PPT 课件**：可在审稿（3—5 个月）期间制作。
6. **索引、图表清单**：审稿一审后再做（编辑会指出索引词表的具体规范要求）。
