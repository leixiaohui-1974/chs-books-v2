| 概念 | 简明定义 |

| **八原理** | 传递函数化 / 可控可观性 / 分层分布式 / 安全包络 / 在环验证 / 认知增强 / 人机共融 / 全生命周期自主演进 |

| **二元水循环** | 王浩院士的自然-社会二元水循环理论 |
| **MBD** | 基于模型的设计 |
| **HDC** | 分层分布式控制三层架构 |
| **Family α** | 统一传递函数族 |

- 学术教材风格、中文标注、可适度真实场景元素

## 十三、生图后回填规范

### 13.1 章节内插图位置

由作者或责任编辑审定，**不交给 LLM 自动插入**。建议位置——

- 章首引导图：放在章节标题之后、§1 之前
- 概念定义图：放在该概念首次出现的段落之后
- 流程/架构图：放在对应论述的小节内
- 总结图：放在章末"小结"或"延伸阅读"之前

### 13.2 图题与图注

由作者审定。建议格式——

```
**图 X-Y　[图题]**

[图注：1—3 句说明本图要表达的核心信息，可附简短的"参见"指向其他章节]
```

### 13.3 共享图的引用规则

共享图（_shared/figures/INDEX.md 列出的）在多卷被引用时，遵循——

- 在权威定义卷使用完整图题与图注
- 在其他卷使用简化标注：**图 X-Y　[主题]（同 T1-CN [图]，详见 T1-CN 第 X 章）**
- 不在每卷重画相同概念的图

### 13.4 失败处理

如果某张图 Codex 反复无法生成达标版本，**不要降低标准凑合用**——

- 改用人工绘图工具（draw.io / Figma / Inkscape）按本文件提示词手工绘制
- 暂时用占位图 + 待补标注，章节修订时再补
- 若该图实属可缺，从对应章节正文中改写为纯文字描述，删去图占位

**宁可缺图，不要劣图**。

### 13.5 后续追加

本文件覆盖**约 47—50 张真正待生图**（共享 2—4 张 + T1 待补 4—5 张 + T1 新 ch00 两张 + T2a 6 张 + T2b 13 张 + T3 9 张 + T4 8 张 + T5 5 张）。

完整书系完成后预计需要 150—200 张图，其余 Tier 3 章节深化图等正文密度补强阶段同步追加。

追加新图请在本文件对应卷的小节末尾追加 Prompt 块，保持统一格式。
