## 图表格式规范

1. **色彩方案**: 蓝色系主色调（#2E75B5, #0062AC），红/黄用于安全标注（#C00000红区, #D4A017黄区），绿色用于正常状态（#2E8B57）
2. **字体**: 中文使用思源黑体或等线，英文使用Arial/Helvetica
3. **导出格式**: 优先SVG（可缩放矢量），备用PNG（300 DPI用于印刷）
4. **命名规则**: `{topic}_{descriptor}.svg`，全小写英文，下划线分隔
