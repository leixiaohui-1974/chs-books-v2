# CHS 书系"本书系导读"页统一模板

> **版本**: v1, 2026-04-28
> **用途**: 投稿稿件中每卷扉页前的固定内容页。各卷投稿前由编辑在版权页之后、目录之前插入本页，并将"本卷"替换为该卷自身的简称。
> **关联文件**: `_shared/series_naming_convention.md`（命名约定权威）、`_shared/concept_authority.md` v2.1（概念权威定义）

---

## 模板正文（每卷固定内容）

```
本书系导读

《[本卷正式书名]》是水系统控制论（Cybernetics of Hydro Systems，简称 CHS）书系的[本卷定位]。

CHS 书系系雷晓辉教授主编的水利智能化方法体系，将控制论（维纳→钱学森的工程控制论传统）、水力学（Saint-Venant 方程及其降阶模型）和现代人工智能（MPC/EKF/RL/LLM Agent）融合为统一的 CPSS（信息-物理-社会系统）框架，面向新一代水网的自主运行需求。书系共 8 卷，互为表里、各有侧重：

| 简称 | 正式书名 | 定位 | 适合读者 |
|------|---------|------|---------|
| 《水控》 | 《水系统控制论》 | 理论母本（学术专著） | 本科生 / 研究生 / 学者 |
| 《觉醒》 | 《水网觉醒》 | 科普版 | 行业从业者 / 决策者 |
| 《建模》 | 《水系统建模与控制》（CHS 教材·上册） | 研究生教材 | 研究生 / 年轻工程师 |
| 《认知》 | 《水系统认知 AI 工程》（CHS 教材·下册） | 研究生教材 | 研究生 / AI 入门者 |
| 《标治》 | 《水网智能化标准与工程治理》 | 工程标准参考书 | 标准制定者 / 评审者 |
| 《平台》 | 《水网操作系统：HydroOS 平台开发》 | 平台架构师参考书 | 平台架构师 / 产品负责人 |
| 《算法》 | 《水网智能决策：算法、视觉与安全》 | 算法工程师参考书 | 算法工程师 |
| 《案例》 | 《CHS 工程案例集：胶东·沙坪·大渡河》 | 全书系附册（电子优先） | 全体读者选读 |

本卷在叙述中遇到其他卷时，使用上表的两字简称引用。例如"详见《水控》§1.5"指本书系第一卷《水系统控制论》第 1 章第 5 节；"参见《建模》第 7 章"指 CHS 教材上册的第七章模型预测控制内容。

**核心概念的权威定义位置**：本书系奉行"一体两面"的工程原则——任何核心概念（如 WNAL 自主等级、ODD 运行设计域、安全包络、HydroOS 操作系统、闭环四预、八原理等）只在《水控》中做完整定义，其余各卷在使用这些概念时只引用不重定义。完整的概念-章节对照见《水控》第〇章 §0.4.4 末尾的"CHS 书系核心概念—权威定义导航"表。

**读者建议路径**：

- **路径 A（行业从业者 / 决策者）**：《觉醒》→《水控》第 0—3 章 →《标治》。建立对 CHS 的直觉理解，能够判断自己管理的工程处于 WNAL 哪个等级。
- **路径 B（研究生 / 年轻工程师）**：《建模》→《认知》→《水控》精读 →《平台》/《算法》选读。系统掌握 CHS 方法体系。
- **路径 C（学者 / 研究者）**：《水控》通读 → Lei et al. 2025 系列论文 →《建模》/《认知》按研究方向选读。
- **路径 D（平台架构师 / 产品负责人）**：《平台》→《水控》第 13—14 章 →《标治》→《算法》。从实现层面切入。

雷晓辉
河北工程大学
[年] 月 [日]
```

## 排版要求

1. **位置**：扉页之后、版权页之后、目录之前
2. **页码**：通常用罗马数字 i, ii, iii ...（与正文阿拉伯页码区分）
3. **字号**：正文同等大小，表格略小
4. **风格**：与各卷整体设计语言一致
