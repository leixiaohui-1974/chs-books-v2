**替换技术实施**：

- Perl 脚本（`/tmp/replace_codes.pl`）按七步执行链处理：(1) "代号+全名"双书名（如`T1-CN《水系统控制论》` → `《水系统控制论》（简称《水控》）`）；(2) 带方括号 § 引用（含范围）；(3) 带方括号 ch 引用（含范围）；(4) 不带方括号 § 引用；(5) 不带方括号 ch 引用（含范围）；(6) 中文章号；(7) 单独卷代号
- 范围表达自动合并：`[T1-CN ch00—ch03]` → `《水控》第 0—3 章`
- 双书名冗余清理：`《标治》 卷《标准与工程治理》` → `《标准与工程治理》（《标治》卷）`
- UTF-8 显式编码处理（`open '<:encoding(UTF-8)'`、`'>:encoding(UTF-8)'`）避免 mojibake
- 跳过 `<!-- 变更日志 ... -->` HTML 注释块（保留历史记录）

**修改范围**：94 个 `_final.md` 文件 + 1 个 `casebook.md`，约 700 处替换。

**正文残留扫描**：
```
排除变更日志注释行后的 T1-CN/T2-CN/T2a/T2b 残留：0
排除变更日志注释行后的 T3/T4/T5 残留：0
全部正文已清零
```

注：`<!-- 变更日志 -->` 内仍保留 13 处历史代号引用（如 "v6 2026-03-03: T2a/T2b分工红线检查"）——这些是 HTML 注释，在正式出版渲染中不显示，且作为编辑历史档案有保留价值。
