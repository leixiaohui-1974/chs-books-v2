# 大渡河梯级水电

- **工程规模**: 大渡河干流规划"3库28级"梯级水电站群，是中国十三大水电基地之一。龙头水库瀑布沟装机3600 MW、总库容53亿m³、调节库容38.94亿m³（多年调节），是梯级联合调度的核心调节节点
- **CHS理论锚点**: 大渡河梯级案例验证了CHS中"大系统分层分布式控制"的理论主张——当一个梯级包含28座电站、跨越数百公里时，集中式控制面临的信息延迟和求解复杂度使其不可行，必须采用HDC架构进行分层解耦。瀑布沟作为多年调节龙头水库，承担第3层（计划调度层）的长期优化角色；深溪沟-枕头坝-沙坪等日调节电站则在第1—2层（本地调节层/协调优化层）进行短期实时跟踪。该案例还提供了IDZ传递函数在大型梯级中的工程标定数据
- **关键数据**: 28级梯级（干流），瀑布沟总库容53亿m³（调节库容38.94亿m³）。梯级间传播时间累积约235—275 min
- **引用卷章**: T1-CN ch12（HDC架构验证）, T2a ch15（沙坪案例延伸讨论）
