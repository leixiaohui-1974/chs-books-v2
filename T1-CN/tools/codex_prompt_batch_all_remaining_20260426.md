## 一、统一生成约束

所有图件统一采用以下约束：

1. 学术教材风格，白色背景，蓝色主调，中文标注为主。
2. 默认横向 `4:3` 构图，建议 `1600×1200` PNG。
3. 优先使用程序化绘制方式，保证结构、中文、箭头、边框、矩阵、热力图与公式标签清晰。
4. 不做海报风、营销风、写实插画风，不做 UI 截图风。
5. 允许保留必要数学符号、缩写和控制术语，如 `u_k`、`y_k`、`θ_k`、`MIL/SIL/HIL`、`MPC`、`IDZ`、`WNAL` 等。
6. 每张图都应直接输出 PNG 文件，不输出解释文档代替图片。
7. 每张图完成后，都应回报输出路径与采用方法，并进入后续人工质检记录。
